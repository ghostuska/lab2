Лабораторная работа №2: Уязвимости веб-приложений (OWASP Top 10)

Описание
Простое веб-приложение на Python (Flask + SQLite), демонстрирующее две уязвимости из списка OWASP Top 10:
1. **SQL Injection (A03:2021)** — обход аутентификации при входе в систему.
2. **Broken Access Control / IDOR (A01:2021)** — получение доступа к закрытым заметкам других пользователей путем изменения ID в URL.

Структура проекта
* `app.py` — уязвимое веб-приложение.
* `exploit.py` — скрипт для демонстрации эксплуатации уязвимостей.
* `fix.patch` — diff-патч, устраняющий уязвимости.
* `requirements.txt` — список необходимых зависимостей.

Инструкция по запуску:
1. Установка зависимостей
```bash
pip install -r requirements.txt
```
2. Запуск уязвимого приложения и эксплойта
В первом окне терминала запустите сервер:
```bash
python app.py
```
Во втором окне терминала запустите скрипт атаки:
```bash
python exploit.py
```
3. Применение патча и проверка защиты
Остановите сервер (`Ctrl + C`), примените патч и перезапустите приложение:
```bash
git apply fix.patch
python app.py
```
При повторном запуске `python exploit.py` обе атаки будут заблокированы.
